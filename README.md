# Plus Highway Accident Report System

A web-based system designed to record and manage highway accident reports. 

## Features
* Secure admin login system.
* Form to submit new accident reports.
* Search functionality to find past reports.

## Technologies Used
* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Database:** MySQL

## How to Run This Project Locally
To run this project on your own machine, follow these steps:

1. **Install XAMPP:** Make sure you have XAMPP installed and running (start Apache and MySQL).
2. **Clone/Download:** Download this repository and place the extracted folder into your `C:\xampp\htdocs\` directory.
3. **Database Setup:** * Open your browser and go to `http://localhost/phpmyadmin/`.
   * Create a new database (e.g., named `plus_db`).
   * Import the `plus_db.sql` file included in this repository into your new database.
4. **Run the App:** Open your browser and navigate to `http://localhost/Plus-Highway-Accident-Report/` (or whatever you named the folder in `htdocs`).
